# 🐼 판다스(Pandas) 문제 해결 방법

판다스를 다루다 예상치 못한 동작이나 에러를 마주했을 때, 가장 확실하고 빠르게 문제를 해결하는 방법은 **최소 재현 가능 예제**(MRE, Minimal Reproducible Example)를 만들어 직접 실행해 보는 것입니다. 

추측에 의존하기보다 작고 단순한 데이터프레임을 만들어 직접 코드로 검증해 보세요. 설령 AI에게 질문하더라도, 직접 실행해 볼 수 있는 **예시 코드**(MRE)를 요청하여 결과를 눈으로 확인하는 습관이 중요합니다.

---

## 🧩 퀴즈 1: 문자열과 숫자가 섞여 있을 때 어떻게 정렬될까?

<img src=https://i.postimg.cc/W11FsJLC/image.png, width=600>

판다스 `DataFrame`이나 `Series`의 한 컬럼에 문자열(`str`)과 숫자(`int`/`float`)가 공존할 때, `sort_values` 함수로 정렬을 수행하면 어떤 결과가 나올까요?

* **1번.** 숫자부터 정렬된다.
* **2번.** 문자열부터 정렬된다.
* **3번.** 문자열과 숫자 상관없이 값의 크기(`1`부터)대로 정렬된다.
* **4번.** 타입이 달라 비교할 수 없으므로 에러가 발생한다.

---

## 💡 해결 방법: MRE(최소 재현 가능 예제)로 직접 실행하기

정답을 맞히기 위해 문서를 뒤지거나 추측하는 대신, 상황을 가장 단순하게 재현할 수 있는 **MRE 코드**를 작성해 실행해 봅니다.

```python
import pandas as pd

# 1. 상황을 재현할 최소한의 데이터 생성 (문자열과 숫자 혼재)
df = pd.DataFrame({
    'col1': ['10', 2, '1', 20]
})

# 2. 정렬 실행 및 결과 확인
df.sort_values(by='col1')
```

### 🔍 실행 결과 및 정답

위 코드를 실행하면 다음과 같은 결과가 출력됩니다.

```text
에러 발생: TypeError - '<' not supported between instances of 'int' and 'str'
```

* **정답: 4번 (에러 발생)**
* **이유:** 파이썬 3 이상에서는 서로 다른 자료형(`int`와 `str`) 간의 크기 비교(`<`, `>`)를 허용하지 않기 때문에 정렬 시 `TypeError`가 발생합니다.
